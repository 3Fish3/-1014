# RoboMaster 电控入门课 · 第一章导览与第二章课件

本地离线三维课件与辅助工具集：
- **第一章**：英雄机器人六场景三维结构导览（开场 → 整车 → 云台 → 底盘 → 发射机构 → 电机过渡），建立机械与电控认知的整体框架。
- **第二章**：十步搭建双轮差速教学小车，操作左右轮，观察箭头与轨迹，最后与英雄机器人整车对照。
- **辅助工具**：独立整车结构查看器（支持表面拾取、设计树过滤、显隐与隔离）与 GLB 装配修复工作台（变换调整与补丁导出）。

## 直接打开与页面入口

本项目所有资源均已离线内嵌，日常教学无需安装 Node.js/Python 依赖包，从根目录执行：

```bash
bash scripts/run_server.sh 8080
```

> **注意**：脚本需要 Bash、Python 3 与 `ss` 命令，默认仅绑定 `127.0.0.1` 本机回环地址。若 8080 端口冲突会自动递增，请以终端输出为准。演示结束按 `Ctrl+C` 停止。必须通过 HTTP 服务访问，**严禁使用 `file://` 双击打开**。

## 三维模型体系与默认模型

项目维护四份核心 GLB 模型（`web/models/`），严格区分用途与工程边界：

1. **STEP 对齐模型 (`hero_robot_step_aligned.glb`，SHA-256: `cfb8cb7d333a7b8a6973424e2b774616604fef250c777530a6cbfa0674c599af`，6,151,364 字节)**：
   - **导览与课堂默认加载**：第一章结构导览（`hero-tour.html`）、第二章课堂 V2 第 10 步对照（`ui-v2.html`）与独立结构查看器（`viewer_full.html`）默认加载此模型；旧版 V1 课件与工作台仍使用原样模型。
   - **装配依据与范围**：仅恢复 **#550–#560 共 11 个子件**在用户提供的 SolidWorks STEP AP214 设计中的局部放置，#549 装配组自身保持单位变换，不改动全车其他 563 个节点。
   - **工程边界**：局部放置一致性经数值验证、位置经用户确认，**未通过整车机械工程认证**；两带轮轴向外形中心仍存在约 3 mm 偏差，同步带工作面齿形、带路由及张紧度未认证，实车电调/主控安装型号与位置待开箱实测核实。
2. **原样模型 (`hero_robot_clean.glb`，SHA-256: `f2eefd1ee718e8c0bebd7490968d5b62b4f99a6b640e57905bb3ef940c374baf`，6,150,804 字节)**：
   - 由原始 CAD（`整车5.glb`）经 `gltfpack -si 0.08` 轻量化并压缩贴图得到。
   - 保留原始 CAD 导出时的偏置子装配（`#549 Yaw轴装配体2.1改` 悬空在原点空间）。
   - **用途**：供 V1 课件、装配工作台读取，并作为历史参考基线与原始导出状态对照（可通过参数 `?assembly=original` 访问）。
3. **旧推定修复模型 (`hero_robot_inferred.glb`，SHA-256: `d85a76bd7a2835362efc5839d71e837dfc34fb9b7470d22fd2e03bc7d95337ff`，6,150,972 字节)**：
   - 基于几何父链世界平移反向补偿的旧推定装配候选（补偿偏移 `[-1.280010819, -1.367624966, -1.386149849]`）。
   - **用途**：仅用于算法/补丁工作台历史对照（可通过参数 `?assembly=inferred` 访问），标记为“未机械核验”，禁止作为默认课件模型。
4. **双轮差速教学小车 (`diff_car_teaching.glb`，SHA-256: `bf561d777edffc595cffcc40b500aa0a646b56145471129e91ae6b410a5f82e7`，50,048 字节)**：
   - 算法程序化生成的长方体、圆柱体与管道构件，轮轴旋转中心与局部原点严格对齐，专供第二章运动学教学。

## 第一章：英雄机器人结构导览

打开 **http://127.0.0.1:8080/hero-tour.html**。
- 讲师手动按“开场 → 整车 → 云台 → 底盘 → 发射机构 → 电机过渡”六个场景推进。
- 支持核心模块高亮、四轮组与驱动电机逐项隔离、一键恢复整车、重播。
- 支持独立 Yaw/Pitch 几何方向箭头展示，不修改 GLB 几何或关节联动。
- 运镜平滑且支持鼠标拖拽立即打断，场景切换自动清理高亮材质。
- 场景 5 底部直达第二章电机与动力教学入口。
- 相关文档：[P0设计与节点映射](docs/hero-tour/P0设计与节点映射.md) · [节点清单](docs/hero-tour/节点清单.md) · [使用与验收](docs/hero-tour/README.md) · [验收报告](docs/hero-tour/验收报告.md)。

## 第二章及工具使用

- **第二章课件 (`ui-v2.html`)**：
  - 上一步／下一步，或 `←`／`→`／`空格`推进；`R` 重播当前步骤动画。
  - 第 7 步点击三次推进指令与执行链，暂停／继续控制传播标记。
  - 第 8 步先点预设动作（前进/后退/左转/右转/停止）；第 9 步开放无数值独立双轮滑块，重置清空运动和轨迹。
  - 固定／跟随镜头切换保持轮速与位姿；鼠标旋转、滚轮缩放。
  - 第 10 步双视区对照，点承载、轮组、驱动、供电、控制五类功能高亮；供电／控制未核实位置不猜测。
  - 哨兵代码抽屉仅供课后静态阅读，不连接硬件。
- **独立结构查看器 (`viewer_full.html`)**：
  - 默认加载 STEP 对齐模型，549 组完整显示；可通过 `?assembly=original` 切换原样参考（默认隐藏 549 偏置组）。
  - 支持 `H` 隐藏、`Shift+H` 显示、`F` 聚焦可见、`Esc` 清除选择，显隐操作严格保持相机视角不主动漂移。详见 [结构查看操作说明](docs/model-editor/structure-viewer.md)。
- **装配工作台 (`model-editor.html`)**：
  - 导入/导出 JSON 装配补丁，在浏览器端生成草稿 GLB；测试脚本可通过 gltf-validator 验证草稿模型，不污染正式课件模型。详见 [工作台方案](docs/model-editor/实施方案.md)。

## 性能、口径与边界说明

1. **体积与内存口径严禁混淆**：
   - 原整车 CAD **206.43 MiB → 5.87 MiB**（文件缩小约 97.2%）；独立网格三角面 **432万 → 21.4万**；几何 bufferView 约 **178.3 MiB → 5.66 MiB**。
   - **上述 5.87 MiB 仅为文件磁盘或网络传输体积，绝对不是浏览器运行时的进程总内存、显存或 GPU VRAM**！
   - 解码后的几何顶点数据、GPU 贴图显存、Three.js 对象开销与浏览器运行时环境相关；无头浏览器软件渲染测试中整车 JS 堆约 35.2 MiB。
2. **测试环境与课堂硬件边界**：
   - 本地自动化测试与 CI 流水线采用 Chromium 无头模式及 SwiftShader 软件渲染引擎，测试仅验证了功能闭环与资源往返稳定性，**软件渲染帧率（约 7–9 FPS）绝不能代替目标电教室投影电脑的物理显卡性能**。
   - 目标投影电脑的实际帧率、字体可读性与峰值进程内存，必须由讲师在现场设备上实测确认。
3. **模型装配与偏置演进说明**：
   - 项目早期（V1 阶段）因缺乏 CAD 机械依据，曾采取“保留偏置不猜测修复”的审慎策略，原样模型（`hero_robot_clean.glb`）至今保留该状态作为历史对照。
   - 随后在 MR-2/MR-3 阶段探索了基于父链平移反向补偿的推定装配候选（`hero_robot_inferred.glb`）。
   - 在 MR-4 阶段，基于用户提供的 SolidWorks STEP 装配基线完成了局部装配对齐，产出 `hero_robot_step_aligned.glb`，第一章导览、第二章第 10 步对照及独立查看器均默认加载此模型（V1 与工作台仍使用原样模型）。旧文档中的“保留偏置不修复”属于 V1 历史记录，不代表当前导览与课堂默认状态。
4. **硬件信息缺项真实披露**：
   - 模型各部件标注仅基于 CAD 历史节点名称，不代表实车在役铭牌已认证。
   - 实车电调、主控板型、供电管理模块的具体型号与空间物理位置，以及真实电池电芯实拍，待硬件开箱实测后补齐。
   - 课件仿真视频由无头浏览器步长录制，非实车运行录像；参考照片不冒充模型同款。

首次开发环境准备与全套脚本命令详见 [脚本使用说明](docs/脚本使用说明.md)。当前交付分支为 `main`。
