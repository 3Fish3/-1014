# RoboMaster 电控入门课 · 第一章导览与第二章课件

本地离线三维课件：十步搭建双轮差速教学小车，操作左右轮，观察箭头与轨迹，最后对照用户整车 CAD。

## 直接打开

已包含运行资源，不必安装 Node/Python 包：

```bash
bash scripts/run_server.sh 8080
```

浏览器打开 **http://127.0.0.1:8080/**。独立整车页：**http://127.0.0.1:8080/viewer_full.html**。Ctrl+C停止服务；默认仅本机可访问。需系统 Python3、`ss`、支持WebGL与import map的现代浏览器。不要用 `file://` 打开。

## 第一章：英雄机器人结构导览

打开 **http://127.0.0.1:8080/hero-tour.html**。讲师手动按“开场 → 整车 → 云台 → 底盘 → 发射机构 → 电机过渡”推进；拖动可取消镜头过渡，恢复整车可结束隔离。页面只做结构展示，不改变冻结模型，不实现真实关节或发射运动。

[P0设计与节点映射](docs/hero-tour/P0设计与节点映射.md) · [节点清单](docs/hero-tour/节点清单.md) · [使用与验收](docs/hero-tour/README.md)。后续动力与电机入口指向已有第二章，不新增第三章。

## 第二章及结构查看器使用

独立整车页支持点选与结构树选择、隐藏／显示、隔离及恢复。当前默认加载STEP对齐模型，549组完整显示；显式 `?assembly=original` 才采用原样参考的默认隐藏策略。详见 [结构查看操作说明](docs/model-editor/structure-viewer.md)。

- 上一步／下一步，或 ←／→／空格推进；R重播。
- 第7步点击三次推进指令与执行链，暂停／继续控制传播标记。
- 第8步先点预设；第9步再开放无数值独立滑块。重置清空运动和轨迹。
- 固定／跟随镜头切换保持轮速与位姿；鼠标旋转、滚轮缩放。
- 第10步并列对照，点承载、轮组、驱动等功能高亮；供电／控制未核实位置不猜测。
- 哨兵代码抽屉仅静态阅读，不连接硬件。

## 性能与边界

原整车 **206.43 MiB → 5.87 MiB**；独立网格三角面 **432万 → 21.4万**，几何数据约 **178.3 MiB → 5.66 MiB**。有损减面，保留574个节点；删除无材质引用的孤立图片，不删可见部件。教学小车约49 KiB。第10步才加载真实整车。

这些不是进程总内存或显存数字。浏览器软件渲染验收通过，十次往返的几何、纹理与着色程序数量保持稳定；目标投影电脑的帧率、峰值总内存仍须现场测量。

**原样 GLB 保留偏置子装配作历史参考**。第一章及当前结构查看器默认使用已确认位置的STEP对齐模型；不等于整车机械认证，同步带路由、工作面及张紧仍未认证。实际主控、电调、供电器件型号与安装位置待核对。参考照片不冒充模型同款；电池电芯实拍尚缺。仿真视频不是实车录像。官方图片许可未明确，限本地教学引用，公开发布前需核查许可。

首次开发环境准备与所有复现命令见脚本说明；授课无需联网。最终仍需讲师在目标投影电脑进行断网试讲。
