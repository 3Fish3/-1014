## 2. 达妙电机 CAN ID 与 Master ID 机制速查

### (1) 为什么 CAN ID = 0x01，Master ID = 0x11 可以正常使能？
在达妙电机的协议体系中，**控制与反馈采用双向不对称的 CAN 标识符**：
1. **CAN ID (从机接收 ID / Motor ID)**：
   * **作用**：电机**接收主控指令**的地址。
   * **使能逻辑**：当主控向总线发送使能报文（`0xFF 0xFF 0xFF 0xFF 0xFF 0xFF 0xFF 0xFC`）时，该报文的仲裁帧 ID（StdID）填写的是电机的 **CAN ID**（即 `0x01`）。电机驱动器在总线上监听到发往自己 CAN ID 的使能帧后，立即激活驱动桥并进入使能状态。
2. **Master ID (主机接收 ID / 反馈 ID)**：
   * **作用**：电机**向上位机/MCU 回传状态报文**时使用的 CAN StdID。
   * **反馈逻辑**：电机收到使能指令后，自身状态切换为使能（反馈报文中的 `ERR = 1`），接着以 **Master ID**（即 `0x11`）作为 CAN StdID 向总线广播自己的当前状态（位置 POS、速度 VEL、扭矩 T、MOS 温度及线圈温度）。
   * 主控 MCU 若要接收并解析电机的反馈，只需在 CAN 接收过滤器或中断中监听 `0x11` 即可。

> **核心结论**：
> 使能指令是通过电机的 **CAN ID (`0x01`)** 被电机接收并执行的；**Master ID (`0x11`)** 并不参与使能的校验或鉴权，它纯粹是电机向外回包时占用的 CAN 报文 ID。两者独立互不干扰。
