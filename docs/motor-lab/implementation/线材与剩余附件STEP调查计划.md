## 结果验收

- 接头板端/线端/公母/系列/键位必须分别记录。总装模型里有插座不等于有配对插头STEP，更不等于有完整线材。
- C板4-pin含5V，中心板2对应4-pin含N/A；没有逐针证据不认可直通。7-pin不是CAN/UART；C615三芯控制线不能直接当作C板UART线。
- 未定具体型号的电源/保护/UART只能给资源候选，不能据模型可用就擅定实物BOM或保险、电流、电压施工参数。
- 主代理收到结果后复核具体链接与格式证据，汇总“明确可用源/候选需核/未检得/访问受阻”及优先级；不依据子代理自述直接宣布全部齐备。
