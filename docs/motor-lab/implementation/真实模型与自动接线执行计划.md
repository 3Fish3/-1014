## 验收顺序（执行依据）

1. **电池/架与接入数据准备（已产出候选）**：源几何只读，电池展示分色、组合姿态候选与输出端；并行核真实器件分组、米单位与端口候选。几何不明确不冒称机械装配通过。
2. **主模型审查后实施**：真实器件替换占位、适当处理附带线束避免重复、建立功能级可插拔线端与柔性线身。未核配对型号/针序持续标未核实；不为了能连而伪造通用直通线。
3. **行为接通**：保持现有SIM唯一状态机和七链路；自动接线与手动插拔同一校验路径；供电总成采用TB47D+电池架、仿真固定24V。自由Orbit/pan/zoom，端口拖线时只暂停相机手势、结束恢复。
4. **主模型验收/定点迭代**：测试先复现再验证，不保留硬编码旧相机与端口位置的假通过。检查真实模型加载、比例/首屏完整、端口贴合、自动七链路、手动拖线、错误拒绝、运行/故障恢复、视角与手机、零外部请求。离屏WebGL不是投影设备实测。
5. **收尾**：更新计划、交接、实际测试证据和剩余风险。源许可、精密机械、实物接线、其他电机独立轴动画不混作本轮验收。
