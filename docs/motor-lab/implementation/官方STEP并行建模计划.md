1. URL/源SHA/实际格式、单位、层级与有效性、包络、完整型号修订和许可状态。
2. 避免重复父子几何，无占位替代；M3508按手册核轴向尺寸/外径/孔位，不能只按文件名认P19。
3. 高细节/网页候选文件、参数、三角数/字节、GLB校验结果。文件大小不等于进程内存。
4. 整体/背面/接口近景实际截图并由执行代理查看，主模型再独立复核；电机轴枢轴和能否单独转动须有几何/分组依据。
5. manifest.json和report.md列确证/未知/未完成，不把阶段产物自述当验收。
