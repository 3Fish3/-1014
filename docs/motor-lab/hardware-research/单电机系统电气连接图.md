# Motor Lab 单电机系统电气连接图

**状态：已确认器件功能关系＋教学抽象拓扑；不是经过实物核对的可上电施工图。** 未指定电源/保险/急停/线规，旧代复合口及四芯转接线仍有缺口。不得据此开展本轮任务范围外的通电操作。

来源编号、版本与页码口径见[调查报告](硬件资料调查报告.md)，逐脚定义见[接口表](设备及接口定义表.md)。

## 1. 选定“中心板2”的功能级单电机拓扑

这里明确选**电调中心板2**，不把旧代8-pin复合口画进同一套接线。中心板不是CAN到UART转换器。

```text
                           【功率/供电】
      [待选定的受保护24V电源；保险/急停/容量尚待核实]
                              │ 电源正负极
                              ▼
                   [中心板2：XT60输入]
                       │          │
            XT30输出A  │          │ XT30输出B
                       ▼          ▼
                 [C板XT30输入]  [C620电源线]
                                    │
                                    │ 三相动力线（原装同色匹配）
                                    ▼
                                 [M3508]

                            【CAN信息】
      [C板：选择一路CAN，本图候选CAN1]
             ⇄ CANH/CANL ⇄ [中心板2并联CAN网络] ⇄ CANH/CANL ⇄ [C620]
             ⚠ 未核实成品线的端子料号/端口视图，不以箭头代表线芯编号

                        【电机侧专用数据】
                     [C620的7-pin口] ⇄ [M3508的7-pin口]
             ⚠ 不是CAN或UART，不把内部每脚供电/协议自行补全

                     【可选UART教学通道，未接入】
             [PC] ⇄ [待选USB→逻辑UART适配器] ⇄ [C板UART]
                       不接中心板CAN口，不接M3508的7-pin口
```

**已确认的器件关系**：[S04](硬件资料调查报告.md#s04)页9–10确认中心板2电源输出与CAN各自并联；[S01](硬件资料调查报告.md#s01)页5/13–14确认C板XT30输入和CAN；[S06](硬件资料调查报告.md#s06)页23–25与[S07](硬件资料调查报告.md#s07)页9确认C620↔M3508两类线。

**教学设计选择**：使用中心板两个独立XT30口分别供C板和C620，帮助区分功率与信号；不让学生将主控小信号输出当作电机动力电源。这一端口分配属于方案示意，不是官方针对本实验的装配记录。中心板不是单电机系统的必需品；若不用中心板，仍需合规电源分配与正确CAN物理连接，本轮不另画未选器件的实接线。

## 3. CAN终端与两路总线边界

```text
      物理主干端A                                  物理主干端B
      [120Ω位置待确定] ======= CANH/CANL ======= [C620：可选择120Ω]
                        中心板及连接线按实际布线计入拓扑
```

- 通用高速CAN主干两端终端原则来自[S08](硬件资料调查报告.md#s08)物理页5；C620通过ON/OFF开关接入/断开120Ω来自[S06](硬件资料调查报告.md#s06)页24。
- **尚未确认**C板当前硬件与中心板当前批次是否已经接有终端、其准确位置；因此不能直接下发“C板端再焊120Ω”或“所有开关ON”的操作指令。
- 若只有两只120Ω并联，理论直流等效为60Ω；这是电路推导，不是本轮万用表实测或总线可靠性验收。
- 中心板2各CAN口物理并联。若C板CAN1、CAN2原计划是两条独立网络，不应把它们同时接入同一并联网络；否则独立网络边界被合并。不能把这一点描述成“只要两个CAN收发器同网就必烧毁”。
- 中心板扩展端口不等于任意长度星形布线均可；实际主干/支线布局须依据高速CAN规则另核。

## 4. 换成旧代中心板时，不能照搬什么

旧代是另一套接口方案：[S02](硬件资料调查报告.md#s02)与[S03](硬件资料调查报告.md#s03)页9/11确认XT60输入、4路XT30/CAN、8-pin供电与CAN复合口。其XT30单口持续20A、总输入持续40A，与中心板2的15A/30A口径不同。

- 旧代8-pin连接的是当时配套主控，不据此直接连接C型开发板。
- 本轮未核实8-pin逐针线序；替换时该连接只能标“待核实”，不能补成四芯CAN2适配线。
- 不从820R的供电范围推断旧中心板完整额定范围，不把旧代参数用于2代。
- 需要旧代实接方案时，应先提供确切板卡版本、官方针序及原装线编号，再单独出图。

## 5. 本图不表示的事情

- 不是C620启用/刷写/ID设置的现场操作流程；本轮不通电。
- 不是英雄整车真实接线；没有对本车主控、中心板、接头和保护装置做实物核验。
- 不是从UART直接发送C620 CAN帧；若未来要转发，必须有明确的软件与传输层设计，不能把本图的箭头当现有实现。
- 没有把电流目标、供电电流、相电流瞬时波形、转矩或轮速混为同一量。
