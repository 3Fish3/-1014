# 第二章讲解文档：从零制造一台能移动的机器人

本章约 14 分钟，位于 90 分钟课程约 6:00–20:00。面向初学者，先提出问题，再加入部件、观察动作，最后回到英雄机器人案例。讲解依据用户《RoboMaster 电控入门课｜第二章教学定稿 v1.0》，不随开发中的页面文案改变。

## 十步讲课手卡

下表时间从本章开始计；“操作”表示定稿要求的演示顺序，课前需按[设计与验收说明](设计思路与流程.md)检查当前页面是否支持。

| 步骤 | 时间 | 讲师操作 | 口播要点 |
|---|---|---|---|
| 01 任务提出 | 0:00–0:45 | 从英雄整车引入，切到空车架 | 如果只造一台能前进、后退、转弯的小车，需要什么？先把目标缩小。 |
| 02 车架和轮子 | 0:45–2:15 | 加入左右驱动轮和辅助支撑轮，观察轮组 | 车架承载部件，轮子接触地面，辅助轮支撑车身。只有轮子，小车还不会自己动。 |
| 03 驱动电机 | 2:15–3:45 | 加入左右电机，指出轮轴连接 | 电机把电能变成旋转运动，再带动车轮。这里用有刷减速电机作教学示意，不要求记型号。 |
| 04 电机驱动器 | 3:45–5:15 | 加入驱动器，指出通往电机的功率路径 | STM32 发指令，普通 GPIO 不能直接提供驱动电机所需的功率。与电机匹配的驱动器负责功率驱动；有刷电机可用 H 桥示意。 |
| 05 电池与供电 | 5:15–6:30 | 加入电池，分别指出动力供电和主控稳压路径 | 电池提供能量。不同设备可能需要不同电压，主控应经过合适的电源分配、稳压路径，不能随意直连动力电池。 |
| 06 STM32 主控 | 6:30–7:45 | 加入主控板并聚焦 | 程序在主控上运行，它决定左右电机怎样转；驱动器和电机负责执行。板卡外观只是教学示意。 |
| 07 指令路径 | 7:45–8:45 | 手动分三次展示：主控发指令、驱动器接收、电机带轮子 | 控制路径是 STM32 → 驱动器 → 电机；供电路径另用色系和文字标明。电机驱动输出传递功率，不能称为主控逻辑信号。 |
| 08 预设动作 | 8:45–10:30 | 依次点前进、后退、左转、右转，最后停止 | 先看两侧车轮方向和快慢，再看车身中心轨迹。左右轮同向等速时直行，速度不同时转弯。 |
| 09 自由调节 | 10:30–12:30 | 让学员先猜，再拖两根滑块；切换固定／跟随视角 | 两轮都向前时，右轮更快会怎样？交换快慢呢？只看方向、快慢、箭头与轨迹，不报转速数字。演示后停止或重置。 |
| 10 回到英雄机器人 | 12:30–14:00 | 左右对照教学小车与真实整车，指出对应功能区 | 结构可以不同，但都需要承载、驱动、供电、控制。实车轮组、电机、驱动器及板卡型号、位置均须核对，未知处写“待核对”。 |

## 核心问题怎么讲

**为什么改变左右轮速度，小车就会转弯？**

先让两轮同向等速，小车沿直线走。再让右轮向前转得更快：同一段时间里，右侧走得更远，车头向左偏；交换两侧快慢，车头向右偏。左右以车头朝向为准，不按投影画面的左右判断。

让学员先预测，再操作揭晓。两轮等速反向可补充演示原地转向，但不展开公式。若箭头、轮子和轨迹不一致，暂停该演示，不能用视觉效果代替正确的运动逻辑。

## 供电与指令的讲解边界

- 能量：电池 → 驱动器 → 电机；电池经合适的电源分配／稳压路径 → 主控。
- 指令：主控 → 驱动器 → 电机执行。用颜色加文字图例区分；功能分工不等于电气隔离。
- 本章只讲用途与直观原理，不讲 PWM/CAN 帧、PID 参数、接线施工或芯片型号。
- 三维运动属于教学运动学示意，不代表真实接触力学、电磁仿真或可直接运行的硬件方案。

## 课前与收尾

按[脚本使用说明](脚本使用说明.md)启动，在投影电脑上走完十步并做断网演练。页面配有原厂及战队参考照片，明确注明非模型同款；SVG仅为示意图。电池电芯实拍尚缺，不把空电池座或蓝色模型当作实拍。第七步三次推进与第十步功能点选已有自动化验证，仍需讲师在投影电脑试讲。

收尾请学员回答：电池、主控、驱动器、电机各做什么？左右轮速度不同为何转弯？随后过渡到第三章“机器人的动力与供电系统”，不在本章提前展开其细节。

哨兵 C++ 代码仅供课后阅读，属于四全向轮参考，不是本章双轮差速教学固件；本课不执行硬件操作。
