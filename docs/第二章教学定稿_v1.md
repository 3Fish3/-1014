# RoboMaster 电控入门课｜第二章教学定稿 v1.0

> **章节名称**：从零制造一台能移动的机器人  
> **课程定位**：90 分钟通用机器人电控入门课的第二章  
> **本章时长**：约 14 分钟（累计课程时点约 6:00–20:00）  
> **受众**：基础参差不齐的新学员；多数不了解机器人  
> **讲解理念**：先提问题、再加部件、再看动作、最后回到 RoboMaster 英雄机器人案例。只解释器件用途和基本原理，不深入公式、底层代码或实际电路设计。  
> **状态**：用户已确认本章教学与交互选择，作为后续开发的基准；若无新要求，不重复征询本章已确认的选项。

## 1. 本章学习目标

学完后，新学员应当能：

1. 指出简化双轮差速小车的车架、驱动轮、辅助支撑轮、驱动电机、驱动器、电池和 STM32 主控板。
2. 用自己的话描述：电池提供能量、主控发出指令、驱动器输出电机驱动所需的功率、电机带动车轮转动。
3. 观察轮子旋转箭头与小车轨迹，定性判断两侧车轮速度或方向改变会怎样改变车辆运动。
4. 在对照画面上找到简化小车与英雄机器人底盘的相似功能模块，同时知道二者结构不必相同。

**本章不要求**：背诵芯片或电机型号、理解公式、推导差速运动学、编写代码、掌握 PWM/CAN 帧或 PID 参数。电机种类与供电基础留到第三章，STM32 细节、通信与 PID 留到后续专门章节。

## 2. 已冻结的教学选择

| 主题 | 确认决定 |
|---|---|
| 机器人案例 | 英雄机器人用于引入和真实工程对照；基础原理由简化双轮差速小车讲解 |
| 模型风格 | 具有真实器件外观、但结构简洁的三维教学小车；不伪装成某款实车的精确复制 |
| 装配步骤 | 车架 → 轮组与辅助支撑轮 → 电机 → 驱动器 → 电池 → STM32 主控 |
| 模型操作 | 按章节手动点击“下一步”，添加、聚焦对应零件；不让动画自动牵着讲师走 |
| 演示顺序 | 先展示前进、后退、左转、右转等预设动作；再开放左右电机独立调节 |

| 差速可视化 | 同时显示车轮旋转方向／快慢箭头和小车运动轨迹 |
| 摄像机 | 固定视角和跟随视角可切换，切换不重置运动状态 |
| 控制关系 | 手动分步展示主控 → 驱动器 → 电机的指令路线；另用不同色系表示电池供电路线 |
| 实车对比 | 结尾左右并列：简化教学小车与英雄机器人底盘，标注等价功能模块 |
| 核心启发问题 | **“为什么改变左右轮速度，小车就会转弯？”** |
| 教学页面 | 三维模型为主；同时配实物照片、2–3 句说明与少量关键词 |
| 运行方式 | 讲师本地电脑运行，通过教室投影，不依赖外网；用本地静态服务启动亦属于本地运行 |

## 3. 14 分钟讲课大纲与 Web 演示分镜

> 表中时间按本章开始计，括号中是 90 分钟课程中的大致累计时间。可在现场微调数十秒，但不把所有操作堆到最后。

| 镜头 | 本章时间 | 屏幕／三维交互 | 讲师讲什么 | 关键认知 |
|---|---|---|---|---|
| 01 任务提出 | 0:00–0:45（6:00–6:45） | 从第一章英雄整车切至简化小车的空车架；标题“怎样让它动起来？” | “先造一台最简单的移动机器人，看看最少需要哪些功能模块。” | 目标先于器件 |
| 02 车架和轮子 | 0:45–2:15 | 手动加入左右驱动轮与辅助支撑轮；局部放大轮子，显示真实轮组照片 | “车架负责承载，轮子接触地面；但只有轮子仍不会自己动。” | 机械基础与支撑 |
| 03 驱动电机 | 2:15–3:45 | 手动加入左右电机；高亮电机连接车轮，右侧显示电机实物图 | “电机把电能转化为运动，驱动车轮旋转。” | 动力从哪来 |
| 04 电机驱动器 | 3:45–5:15 | 加入简化电机驱动板；高亮与电机相连的功率线位置 | “STM32 负责发指令，但不能用普通 GPIO 直接向驱动电机提供所需功率；要有驱动器。” | 指令和功率分工 |
| 05 电池与供电 | 5:15–6:30 | 加入电池；高亮电池→驱动器，以及合适的电源分配／稳压模块→主控（示意） | “电池供电；不同设备可能需要不同电压，不能随意直接连接。” | 电从哪里来 |
| 06 STM32 主控 | 6:30–7:45 | 加入主控板，镜头聚焦；展示实物照片 | “程序在主控上运行，它根据命令决定左右电机怎样转。” | 决策与执行分离 |
| 07 指令路径 | 7:45–8:45 | 分 3 次点击，依次高亮“主控发指令→驱动器接收→电机带动车轮”；供电路径用不同颜色静态显示 | “控制指令与电能走的是不同的路径，但缺一不可。” | 控制信息与电能不同 |
| 08 预设动作 | 8:45–10:30 | 手动点前进、后退、左转、右转；轮子方向箭头、速度快慢和地面运动轨迹同步变化 | “看一看不同轮速怎样影响车身方向。” | 从现象建立直觉 |
| 09 自由调节 | 10:30–12:30 | 开放左、右两根独立滑块（无数值），支持正／反转与停止；切换固定／跟随视角 | “如果右轮比左轮快，会发生什么？交换快慢又会怎样？”让学员猜，再操作揭晓。 | 本章核心差速概念 |
| 10 回到英雄机器人 | 12:30–14:00（18:30–20:00） | 左右对照：教学小车 vs 英雄机器人底盘；点选高亮对应的轮组、驱动、电源、控制功能区 | “具体机械结构可能不同，但仍需解决承载、驱动、供电、控制这些共同问题。”承接第三章 | 将通用知识映射到真实工程 |

### 本章优先保留的一个问题

**“为什么改变左右轮速度，小车就会转弯？”**

讲法：先点“前进”，两侧轮速一致；然后使右轮更快，显示左弯曲轨迹；再交换两侧速度关系，观察轨迹方向改变。无须提供线速度、角速度、转弯半径等公式。注意转弯方向须以模型坐标、轮轴方向和运动学一致性实际测试为准，不能只用视觉假动画代替逻辑。

## 4. Web 页面与交互规格

### 4.1 投影画面布局

- **主要区域**：三维教学小车，支持常见的旋转、缩放与镜头平滑聚焦。
- **辅助手册区**：当前步骤标题、真实器件照片、2–3 句简短解释、1–3 个关键词。
- **控制条**：上一步、下一步、当前步骤、重播本步骤；运动演示时显示预设动作按钮。
- **仿真控制区**：左轮和右轮各一根双向滑块，中心为停止，左／右表示反转／正转；只用文字、方向图标及动画快慢反馈，**不显示 RPM、百分比、PWM 数字**。
- **视角切换**：固定镜头／跟随镜头。切换时不重置车辆位置、轮速或轨迹；提供“重置场景”。

### 4.2 分步播放与状态

1. 整个教学章节由讲师手动推进；装配动画、控制链动画每一步都能暂停与重播。
2. 预设动作与自由滑块不可出现互相打架：触发预设动作时同步刷新内部左右轮目标状态；手动拖动任意滑块后转入“自由调节”模式。
3. 滑块不显示数值，但内部可以使用带符号的归一化速度模拟正反转；箭头必须能够表示“转得快／慢”和方向。
4. 无数值要求只针对给学员看的 UI，不禁止内部使用数值完成动画计算与一致性验证。
5. 小车运动应与轮速方向和大小保持一致；轨迹表示车身中心路径，不应是与运动无关的预录贴图。
6. 演示模式应具备明确的“停止／重置”操作，避免投影时小车持续驶离视野。

### 4.3 线路示意

- **供电**：电池 → 电机驱动器 → 电机；电池经合适供电／稳压路径 → 主控，避免暗示裸电池可以随意直连 STM32。
- **控制**：STM32 → 驱动器 → 电机。
- **反馈**：本章只作为概念提示，可在后续传感器和闭环章节展开，不要求本章模拟闭环。
- 若小车使用有刷直流电机，示意使用对应电机驱动器（如 H 桥），不要误写成所有电机都需要 RM 无刷电调；切换到英雄机器人时再介绍其具体驱动方案。
- 线路颜色应始终一致，配文字图例，避免仅靠颜色辨认。

### 4.4 工程边界

- 只做**教学层面的运动学示意**，不宣称是真实接触力学或电机电磁仿真。
- 简化模型中的电子器件若非真实装配零件，页面需标注“教学示意”。
- 英雄机器人的底盘形式、轮组类型、电机型号和实际安装位置须以 CAD／GLB 和战队资料核验；未知时显示“待确认”，不得补造事实。
- 本地部署应尽可能使用已打包依赖和本地静态资源，避免依赖在线 CDN 或在线照片；课前完整离线演练。

## 6. 讲师口播关键句（可按个人风格调整）

**开场**：
> 刚才我们看的是能移动、瞄准和发射的英雄机器人。现在先把问题缩小：如果只要造一台能前进、后退、转弯的小车，我们需要哪些东西？

**主控、驱动器、电机的关系**：
> 程序在主控板里运行，主控板决定怎么转；驱动器按照指令向电机提供合适的驱动；电机真正带动车轮。电池则为它们供电。

**运动演示**：
> 我们先不看数字，只看左右轮的方向和快慢。两侧一样快的时候会怎样？如果一侧更快，小车会向哪边转？

**结尾过渡**：
> 我们做的是一台最简单的教学小车，但真实英雄机器人的底盘也要解决动力、供电和控制这些问题。下一章，我们把其中最重要的电池、电机和驱动器拿出来，看看它们到底怎样工作。

## 7. 开发与教学验收清单

- [ ] 14 分钟内可走完 10 个讲解镜头，靠“上一步／下一步”控制，不依赖自动播放。
- [ ] 车架、轮子、电机、驱动器、电池、主控可以按步骤独立安装／高亮；右侧对应显示真实照片和简要介绍。
- [ ] 预设动作涵盖前进、后退、左转、右转、停止，视觉结果符合差速运动逻辑。
- [ ] 左右滑块可独立调节方向和快慢；UI 完全不显示转速数字。
- [ ] 轮子方向箭头、相对旋转快慢和小车地面轨迹相互一致。
- [ ] 固定／跟随视角切换成功，切换不重置小车运动。
- [ ] STM32→驱动器→电机的指令流程可以手动分段播放；供电与控制线有清楚区分。
- [ ] 结尾可同屏对照简化小车和英雄底盘，且没有臆造英雄机器人的具体底盘形式与零件型号。
- [ ] 在计划使用的投影电脑上可离线打开所有照片、模型与演示资源。
- [ ] 讲师实际试讲后，新人可以用非专业语言回答：电池、主控、驱动器和电机分别干什么，以及为什么左右轮速度差会导致转向。
