## 云台同步带传动关系

用户已确认：原样模型中悬空的 `#549 Yaw轴装配体2.1改` 是云台配套传动装配，应位于另一同步带轮旁，两者通过**同步带连接**，共同驱动云台Yaw水平转动。

- 该组不是多余电机，不应删除，也不应按齿轮直接啮合摆放。
- 目前独立查看页仍默认隐藏该偏置组，只是展示处理；点击“全部显示”可以恢复。
- 既有推定候选补偿了该组的重复平移，但仍标记“未机械核验”，没有替换原样默认模型。
- 本次确认了传动方式和功能关系；实际安装坐标、中心距、带规格及带路由仍待核对。
- 本阶段尚未补建同步带，也未实现带轮联动或云台旋转动画。本次只记录完成情况，不调整装配或默认显示策略。

## 使用入口

在项目根目录启动：

```bash
bash scripts/run_server.sh 8080
```

脚本需要Bash、Python 3和 `ss`。默认绑定本机回环地址，端口占用时会递增，请以终端输出为准。

- 独立结构查看：<http://127.0.0.1:8080/viewer_full.html>
- 第二章课堂：<http://127.0.0.1:8080/ui-v2.html>
- 装配工作台：<http://127.0.0.1:8080/model-editor.html>
- 推定候选对照：<http://127.0.0.1:8080/ui-v2.html?step=10&assembly=inferred>

独立查看器快捷键：`H` 隐藏、`Shift+H` 显示、`F` 聚焦、`Esc` 清除选择。搜索框或按钮等元素获得焦点时，相关快捷键不触发。
