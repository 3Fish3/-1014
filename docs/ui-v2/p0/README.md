## 展示层改动

- 独立蓝白投影样式，不叠加旧HUD的CSS。顶栏、左侧演示台、右侧单知识点卡片、底部导航分区。
- 正文1080p为24px，768p为22px。按钮、词条和标题可读；照片按可用高度伸缩，避免文字压在图片上。
- 控制板独占布局空间，不覆盖画布。主画面不展示讲师讲稿、源代码、RPM或PWM数值。
- 根据当前可见顶点与画布宽高比拟合镜头，保留车架/电机安装关系；模型实际投影高度约占画布65%（第3步）、61%（第9步，含箭头）。
- 仅V2对每个功能节点使用独立材质，避免聚焦电机时整车一起发光。蓝色指令、橙色供电；反馈图例明确为“待讲解”，本轮未伪造传感器或反馈信号。
- 轮速文字简化为“停止／慢速正转”等；原有速度分段判定和运动学保持不变。
- 进入跟随时取消未完成的初始运镜；暂停中归位也同步镜头，修复复测中发现的车体越界。

## 验收命令与结果

```bash
npm test
node scripts/ui_v2_check.mjs http://127.0.0.1:8080
```

- 原有6项运动学测试全部通过，`kinematics.js`及其测试文件没有修改。
- 双分辨率检查：无横向溢出、右卡片无滚动溢出、模型与箭头投影未裁切、图片成功加载、正文至少22px。
- 实际键盘操作滑块验证独立正反转；预设同步、自由调节取消预设高亮、轨迹生成、暂停状态保持、视角切换不改变轮速、归位、全屏进出均通过。
- 跟随及全屏进出后的几何/箭头仍在画布内，轮速文字不溢出。讲师备注默认关闭、源码默认隐藏。
- 所有请求离线本地，无页面异常、404或外网请求。详细数据见 [browser-results.json](browser-results.json)。
- V1完整浏览器回归也通过；为保护原交付证据，本轮输出在 `.tmp/ui-v2-v1-regression/`，不是重写旧截图。
- 改动路径的主动LSP检查未报告错误：5项确认clean，1项推送式服务未能确认，不能将其算作全项静态检查通过。会话辅助规则仍提示V1既有的嵌套表达式、console.warn，不借UI任务重构它们。新增的嵌套表达式与CSS important已清理；实际运行由上述浏览器回归覆盖。
