# GLB 装配修复工作台：MR-1 / MR-2

## 交付范围

基线为 `feat/ui-v2-p1` 的 `1fc1877`（含上轮CI输出隔离修复），开发分支 `feat/model-assembly-editor`。

已提供独立浅色离线工作台：加载、节点树搜索、拾取、源节点映射、局部位置/角度输入、移动/旋转手柄、局部/世界操作轴、50级撤销重做、节点/全部复位、隔离隐藏、JSON补丁与GLB草稿下载。讲师工具内有入口，不改变学生主画面和课堂模型选择。

**本次完成的是修复工具，不是经机械核验的安装位置。MR-3尚未执行。** 没有自动放回电机、删零件、猜装配关系或替换课堂整车文件。

## 使用

```bash
bash scripts/run_server.sh 8080
```

打开 <http://127.0.0.1:8080/model-editor.html>：

1. 点击“加载课程整车”，或通过“打开GLB”选本机文件。模型只在浏览器内解析，不上传。
2. 搜索或展开左侧节点树；也可双击模型拾取。原始索引而非名称用于识别节点，同名节点不混用。右栏显示源路径、父节点、局部/世界位置、包围盒。
3. 点击异常候选只聚焦观察，不修改模型。候选是距离中位中心较远的统计结果，不等于装配错误或电机分类。
4. 选择真实父装配组可一起移动子树；叶节点仅移动自身。W移动、E旋转、F聚焦，Ctrl+Z撤销、Ctrl+Shift+Z重做，Esc取消选择。输入框聚焦时不抢快捷键。
5. 数值输入始终是**局部坐标**；操作轴切换只改变手柄方向。位置单位沿用源文件，不擅自解释成毫米。角度输入为度，内部为四元数；不开放缩放。
6. 先保存JSON，再导出GLB草稿。两种下载不会覆盖服务器仓库。JSON绑定原GLB的SHA-256、字节数、节点索引路径、原始与修复局部变换及说明；重新打开补丁必须先加载相同源模型。
7. 初版均标为“人工调整，待机械核验”，没有将软件导出等同CAD约束恢复的选项。确认实际位置后才由后续阶段审核并集成课堂。

“镜头暂排统计离群件”只改变观察包围盒，不隐藏、删除或改写零件。隐藏/隔离也不导出。关闭页面时未保存的编辑或说明会提示。

## 数据安全与导出

- 直接使用原始 `gltf.scene`，不经过课堂归一化包装。
- GLTFLoader `getDependency('node', index)`与挂载检查建立源节点映射。无法稳定映射或源变换不可分解的节点只读。
- GLB首版拒绝外部资源、动画、骨骼及不支持的必需扩展；支持本项目未压缩几何和 `KHR_materials_unlit`。只支持单内嵌buffer，外部资源不会静默联网。
- 编辑拒绝不可逆、剪切、非均匀父缩放以及镜像父链。后者是r180手柄世界旋转的安全边界，不通过错误近似放行。
- 原来是matrix就写matrix，否则写TRS；不把相机、辅助轴、框选、高亮、网格或归一化容器写入GLB。
- 重建JSON chunk的4字节对齐，BIN及未知合法chunk逐字节保留。导出前比较非目标JSON结构，再用GLTFLoader重新装载。
- 补丁导入先验证源与全部字段，再整体检查最终父子状态；失败回滚所有节点。装载及异步保存期间的编辑变化不会被静默吞掉。

## 异常节点发现

完整清单见 [异常候选.json](异常候选.json)。本源模型574个节点全部建立挂载映射。离群候选集中在：

`#389 云台2(齿轮改) → #543 yaw轴3改 → #549 Yaw轴装配体2.1改`

其中 `#553` 为“云台支架基座加工件4.0-1”，原世界中心约 `[2.5850, 2.7728, 2.7723]`，含同步带轮、挡边板、螺栓等邻近候选。因此不能只按外观将其命名为“一个飞离电机”并自动归位。实际应移动哪层装配、安装位置和姿态，仍待CAD或机械照片核对。
