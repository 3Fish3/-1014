## 为什么这样尝试

原GLB父链 `#1 整车5 → #389 云台2(齿轮改) → #543 yaw轴3改` 的旋转/缩放均为单位变换，累计平移为：

```text
[1.280010819, 1.367624966, 1.386149849]
```

`#549 Yaw轴装配体2.1改` 原本没有平移，但它的11个子件坐标却集中在上述绝对位置附近，而同属`#543`的其他零件已经在原点附近。至少7个中心件的X/Z坐标与父原点几乎完全重合。这支持“局部坐标误用了上层全局坐标、再次叠加平移”的假设。

候选**只设置`nodes[549].translation`**为上述向量的相反数：

```text
[-1.280010819, -1.367624966, -1.386149849]
```

不改`#543`，不分别移动11个子件，不旋转或缩放、不删节点、不补造几何，也不靠隐藏消除悬空。

## 支持证据与尚不能断言的地方

详细量化见 [几何依据.json](几何依据.json)。均以同一个GLB坐标系计算：

- 补偿后`#552 外环轴承座`底面与`#547 云台底座板`顶面高度差约`-3.62e-8`源单位，接触面几乎重合。
- 轴承座中心轴相对底座原点XZ偏差约`[1e-9, 3.1e-8]`。
- 从两块接触平面的网格边界提取出4个小孔轮廓，求外接圆并与现有螺栓轴线对照：底板两孔误差小于`4e-9`，轴承座两孔约`3.5e-5`源单位。简化网格只有少量边界点，不能把圆拟合精度当作制造精度。
- 主动/从动零件的轴向几何范围有约`0.008`源单位重叠。
- **两个标为45齿的零件中心距约0.115，不能仅凭名称断言直接啮合。** 现有结构也包含同步带轮/挡边板命名，缺少原设计和照片，无法确认实际传动形式、皮带或其他缺件。没有为了“看着啮合”再任意调整中心距。
- 近景未见该组明显悬空；未进行全面实体布尔碰撞/装配公差认证。底板接触不代表所有零件机械关系已经正确。
