# 独立机器人结构查看

入口：<http://127.0.0.1:8080/viewer_full.html>。使用 `bash scripts/run_server.sh 8080` 启动静态服务后打开，无需联网。

## 本次默认显示

按用户确认，独立查看页只在内存中隐藏 `#549 Yaw轴装配体2.1改` 及其子结构的显示。加载时核对真实源索引、原名以及父层级 `389 → 543 → 549`，不按外观猜“多余电机”。这是网页显隐，不是删零件、修复安装关系或认证该装配无用。

- 原样 `hero_robot_clean.glb`、候选 `hero_robot_inferred.glb` 和补丁均不改动。
- 课堂 V1／V2 第10步的默认模型与显示策略不变。
- 独立页仍加载原样文件，不自动采用推定候选；原样悬空组可随时恢复查看。
- 不提供源文件写入或永久删除功能；刷新页面重新应用默认隐藏。
- 这是结构观察，不新增轮组、云台运动或动力学仿真。

## 操作

| 操作 | 结果 |
| --- | --- |
| 单击几何 | 选择最近的可见表面对应的真实CAD源节点，橙框提示 |
| 拖动／滚轮 | 旋转／缩放相机；拖动松开不会误选新节点 |
| 结构树／搜索 | 根据名称或索引选择，包括已隐藏节点；显示“自身隐藏／祖先隐藏”状态 |
| 选择父组 | 上移到真实CAD父装配，适合整组隐藏 |
| 隐藏选中／H | 隐藏当前组或零件；子结构暂不可见，不重写它们各自的隐藏设置 |
| 显示选中／Shift+H | 打开当前节点和必要祖先，但保留其他子件自己的隐藏状态 |
| 隔离选中 | 临时只显示所选子树与必要祖先；包含原本隐藏的子件 |
| 退出隔离 | 准确恢复进入隔离前的全部显隐快照；切换隔离目标不覆盖原快照 |
| 全部显示 | 结束隔离并显示所有结构，**包括549** |
| 恢复默认 | 结束隔离并恢复初始状态，重新隐藏549 |
| 聚焦选中／F | 根据选中子树的实际可见几何取景 |
| 适配可见结构 | 根据当前可见结构重新取景，不计入隐藏组 |
| Esc | 清除选择，不改变显隐 |
| 自动旋转／线框 | 仅切换观察效果，不写入GLB |

隔离期间执行隐藏或显示会先恢复隔离前状态，再执行该操作。搜索框或按钮获得焦点时不响应H/F等快捷键，避免输入被截走。

隐藏、显示、隔离、退出隔离、全部显示和恢复默认均保持当前相机位置、朝向与观察目标，不自动重置视角。需要重新取景时，手动点击“适配可见结构”或“聚焦选中”（F）。若整车全部隐藏，保留有限相机状态并提示“没有可见几何”；可以用结构树或“全部显示”恢复。已隐藏几何不会参与鼠标拾取或手动取景。

## 实现边界

复用 `SceneViewer` 和唯一WebGLRenderer。`loadHeroRobot()`只补存真实 `cadNodeIndex` 元数据供选择映射；未给多primitive生成的子Mesh伪造独立源索引。合成Mesh点击沿父链归属到真实源节点。

显隐控制器：`web/js/structure-visibility.js`。隔离保存完整对象快照，包含非源节点的多primitive子Mesh。选择使用辅助框，不克隆或污染共享材质。相机拟合逐个累积实际可见Mesh自身几何，避免 `Box3.setFromObject()` 把隐藏子件也计算进去。

显隐、框选、线框及相机均只存在于当前浏览器实例，不改动模型局部变换或文件。页面退出释放资源；合成的 `pagehide.persisted` 分支保持资源，不能据此认证所有浏览器实际bfcache行为。
