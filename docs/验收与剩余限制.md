## 内存与性能实测口径

最终GLB为6,150,804字节（5.87MiB），几何bufferView合计5,937,504字节（5.66MiB）。原文件216,455,776字节、几何186,928,084字节。上述几何数据是源buffer范围之和，不是含复制、JS对象、驱动缓冲的完整峰值内存。

最新浏览器记录见`browser-results.json`：1600×1000、Chromium无头、SwiftShader软件渲染，教学加载约1.79秒，随后整车约0.39秒（本机文件缓存与软件解码环境）。整车JS堆样本约35.2MiB，**不是浏览器进程总内存/峰值/RSS/显存**。与原始206MiB模型没有做同条件进程峰值对照，不能声称总内存下降97%。

整车30帧样本中位150ms、P95约166.7ms；此前运行中位约117ms。软件渲染约7–9FPS，**不满足流畅60FPS承诺**。实际投影电脑GPU尚未测量。资源往返稳定证明本次测试没有观察到持续资源增长，不是长期无泄漏证明。

当前可交付结论：本地离线V1可运行、资产轻量化与课堂交互可验证；目标设备流畅度和总内存验收保留。

## 仍缺少／须现场核验

1. 源CAD偏置子装配：保留原样，不猜测重装。需机械同学确认原始装配导出。
2. 完整同款电池电芯实拍；目前只有电池座等参考照片，不冒充同款。
3. 整车电调、主控、电源板的准确型号与空间位置；未确认处不强行高亮。
4. 外部原厂图片未找到明确公开再分发许可，仅作本地教学引用。公开发布前须替换自有照片或获得许可。
5. 实拍照片属于不同案例参考，不据此确认英雄模型配置。
6. 目标投影电脑断网试讲、峰值总内存、真实GPU帧率和新人理解效果。

## 本地恢复点

`main`为初始检查点；最终交付在`feat/v1-validation`提交，不推送远端、不重写历史。无需重建即可用`bash scripts/run_server.sh 8080`运行。讲义、设计、操作说明及PDF在`docs/`，媒体在`docs/media/`，输入设计副本在`docs/第二章教学定稿_v1.md`。
