# 脚本使用说明

## 1. 只想上课：无需安装开发包

对于日常授课或现场演示的讲师，系统已内置全部模型、脚本与贴图资源。**无需安装 Node.js、npm 依赖包或 Python 复杂第三方库，绝不需要在每次打开课件前执行重建、测试或导出脚本**。

从项目根目录执行：

```bash
bash scripts/run_server.sh 8080
```

- 主课件入口：打开 `http://127.0.0.1:8080/ui-v2.html`。根路径 `/` 仍进入旧版 V1，不是新版课堂入口。
- 独立整车结构查看器：`http://127.0.0.1:8080/viewer_full.html`。
- 若 8080 端口被占用，脚本会自动递增端口号，终端输出即为实际访问地址。
- 演示结束在终端按下 `Ctrl + C` 即可关闭服务。
- 默认仅绑定 `127.0.0.1`，不向同局域网设备或公网暴露。
- 仅需系统原生 `python3`、`ss` 命令与支持 WebGL 的现代浏览器。严禁使用文件管理器直接双击 HTML 文件。
- 已有验收覆盖 1920×1080、1366×768。启动脚本按 Linux 的 Bash、Python 3 和 `ss` 环境使用，其他平台尚未验证。

## 2. 课堂与独立查看器操作快捷键

### 2.1 课堂课件 (`ui-v2.html`)
- `→` / `空格键` / 点击“下一步”：推进至下一教学步骤；`←`：返回上一步；`R`：重新播放当前步骤动画。
- **第 7 步**：点击底部“推进指令链”按钮 3 次，依次观察主控、驱动器、电机的高亮与传播标记。
- **第 8 步**：点击预设动作按钮（前进／后退／左转／右转／停止），直观观察两轮转向与小车移动。
- **第 9 步**：拖拽左右轮滑块，中位停止，两端对应相反转向；点击“固定视角 / 跟随视角”切换运镜，不重置运动状态。
- 点击“暂停演示”可随时冻结仿真，画面仍可自由拖拽旋转；点击“归位”（或“重置小车位置”）清空运动轨迹、轮速与位姿。
- **第 10 步**：点击“承载车架、动力轮组、驱动电机、电源管理、电调与主控”五类功能高亮按钮；英雄侧供电与主控位置未核实时如实提示。
- 讲师工具备忘抽屉与代码抽屉仅用于静态阅读，不编译、不连接 CAN 总线、不驱动任何实体电机。

### 2.2 独立结构查看器 (`viewer_full.html`)
- **鼠标左键单击**：表面拾取真实源节点，左侧设计树同步定位；**鼠标拖动 / 滚轮**：旋转与缩放镜头（拖动松开不误触拾取）。
- `H`：隐藏当前选中的零部件或装配组；`Shift + H`：显示当前节点并打开必要祖先，保留组内其他零部件隐藏状态。
- `F`：聚焦当前选中的可见结构；点击“适配可见结构”按钮：按当前全部实际可见几何重新计算相机视野。
- `Esc`：清除当前高亮包围框与选中状态。
- 隐藏、显示、隔离、退出隔离、全部显示、恢复默认不主动调整相机；按 `F` 或点击适配按钮才重新取景。自动旋转、拖动阻尼及窗口尺寸改变仍可能移动镜头。

## 3. 首次开发与测试环境准备（需要联网）

以下环境仅供工程维护、模型重建、文档导出与自动化测试开发使用，**不用于授课当天临时准备**：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
npm ci
npx playwright install chromium
```

- 若系统虚拟环境未预装 pip，可使用 `uv pip install --python .venv/bin/python -r requirements.txt`。严禁向系统全局 Python 环境随意安装依赖包。
- 依赖下载须遵循本地网络代理策略（HTTP 代理 `http://127.0.0.1:7897`，npm 可配置 `npm_config_proxy`，Playwright 可配置 `HTTPS_PROXY`）。代理不可达时应停止下载并排查，不得静默绕过。
- 当系统默认 Playwright 浏览器受当前发行版限制时，可通过环境变量指定系统 Chromium：`BROWSER_PATH=/绝对路径/chrome`。

## 4. 常见环境变量与传参逐脚本实况

为防止使用时误套通用参数，特对各脚本的环境变量与参数支持情况做严格界定：

1. **`BASE_URL` 环境变量**：**本项目所有 Node.js 浏览器测试脚本均未读取 `process.env.BASE_URL`**！测试目标服务的 HTTP 地址统一通过**第 1 个命令行参数**（`process.argv[2]`）传入（默认多为 `http://127.0.0.1:8080` 或 `http://localhost:8090`）。切勿试图通过设置 `BASE_URL=...` 传递地址。
2. **`OUTPUT_DIR` 环境变量**：仅部分测试与审计脚本支持 `process.env.OUTPUT_DIR`。凡支持该变量的测试脚本，在持续集成或本地复现时**强烈推荐指定 `OUTPUT_DIR=.tmp/...`**，以防止覆盖 `docs/` 目录下已正式提交归档的验收报告与截图。需要特别注意：`export_docs.mjs` 和 `record_demo.mjs` **完全不支持 `OUTPUT_DIR`**，其输出路径已固定硬编码在 `docs/pdf/` 和 `docs/media/` 中。
3. **`BROWSER_PATH` 环境变量**：所有调用 Playwright Chromium 的脚本均支持 `BROWSER_PATH`。若未设置，脚本将优先检测 `.tmp/browser/chrome-linux/chrome`，若不存在则回退至 Playwright 默认的 `chromium.executablePath()`。

## 5. 全套 20 个脚本详尽使用手册

### 5.1 服务启动脚本

#### 1. [scripts/run_server.sh](../scripts/run_server.sh)
- **用途**：启动本地轻量离线 HTTP 静态服务器，服务 `web/` 目录。
- **前置条件**：系统安装 Python 3 及 `ss` 端口检测工具。
- **执行命令**：
  ```bash
  bash scripts/run_server.sh 8080
  ```
- **输入**：`web/` 目录下的静态前端文件。
- **输出**：终端启动日志，本地 HTTP 监听进程（绑定 `127.0.0.1`）。
- **覆盖风险**：**无风险**。纯只读服务，不生成或修改任何磁盘文件。
- **参数与环境变量**：第 1 个参数为起始监听端口（默认 `8080`，范围 1024–65535，遇冲突自动递增）。不支持任何环境变量。

### 5.2 教学小车与图解生成脚本（资产维护）

#### 2. [scripts/generate_diff_car.py](../scripts/generate_diff_car.py)
- **用途**：程序化构建简化双轮差速教学小车三维模型，使轮组旋转轴严格对齐局部原点（避免转动动画发生绕车身公转），各功能件独立具名。
- **前置条件**：激活虚拟环境并安装 `trimesh`、`numpy`。
- **执行命令**：
  ```bash
  .venv/bin/python scripts/generate_diff_car.py
  # 或指定自定义输出位置：
  .venv/bin/python scripts/generate_diff_car.py web/models/diff_car_teaching.glb
  ```
- **输入**：脚本内嵌算法程序化生成的长方体、圆柱体与走线管道。
- **输出**：生成 GLB 二进制模型文件（默认 `web/models/diff_car_teaching.glb`）。
- **覆盖风险**：**高风险**。默认直接覆盖课件的核心模型 `web/models/diff_car_teaching.glb`。
- **参数与环境变量**：第 1 个参数可选指定输出 GLB 路径。不支持环境变量。

#### 3. [scripts/generate_diagrams.py](../scripts/generate_diagrams.py)
- **用途**：重新生成课件手卡与界面专用的 10 张深色背景高保真矢量教学图解（SVG）。
- **前置条件**：Python 3 标准库（无需安装第三方包）。
- **执行命令**：
  ```bash
  python3 scripts/generate_diagrams.py
  ```
- **输入**：脚本内建的 SVG 拓扑字符串。
- **输出**：`web/assets/images/` 目录下的 10 张 SVG 文件（`frame.svg`、`wheel.svg`、`motor.svg` 等）。
- **覆盖风险**：**中风险**。直接覆盖 `web/assets/images/` 目录下的对应 SVG 图像。
- **参数与环境变量**：无参数，不支持环境变量。

### 5.3 英雄模型轻量化与装配处理脚本

#### 4. [scripts/optimize_models.py](../scripts/optimize_models.py)
- **用途**：调用本地 `gltfpack`（`-si 0.08`）对原始 200MB+ CAD 导出模型执行有损几何简化，并联动 `resize_glb_textures.py` 压缩贴图与清理孤立 bufferView。
- **前置条件**：已执行 `npm ci`（存在 `node_modules/gltfpack/cli.js`），虚拟环境中已安装 `Pillow`，且拥有原始未压缩 CAD 文件（如 `整车5.glb`）。
- **执行命令**：
  ```bash
  .venv/bin/python scripts/optimize_models.py /绝对路径/整车5.glb
  ```
- **输入**：原始大型 CAD GLB 文件。
- **输出**：轻量化后的生产模型 `web/models/hero_robot_clean.glb`（约 5.87MB）。
- **覆盖风险**：**高风险**。直接覆盖生产模型 `web/models/hero_robot_clean.glb`。
- **参数与环境变量**：第1个参数可传源CAD路径；不传时按脚本内的本机Downloads、下载目录及项目 `assets/整车5.glb` 候选路径寻找。跨机器使用建议显式传路径。没有自定义环境变量。

#### 5. [scripts/resize_glb_textures.py](../scripts/resize_glb_textures.py)
- **用途**：将内嵌图片最长边缩至512像素以内并转为PNG。仅在模型没有 `textures` 且没有 `extensionsUsed` 时，删除未被accessor引用的图片bufferView并重映射索引；不提供通用的材质引用清理。
- **前置条件**：Python 3，安装 `Pillow`。
- **执行命令**：
  ```bash
  .venv/bin/python scripts/resize_glb_textures.py web/models/hero_robot_clean.glb
  ```
- **输入**：待处理的受控项目输出 GLB 文件。
- **输出**：**原地修改覆盖原 GLB 文件**，控制台打印图片压缩前后分辨率与字节统计。
- **覆盖风险**：**极高风险**。该脚本直接修改目标文件本身！仅可用于本项目生成的输出模型，严禁作为通用的无损清理器随意施加于未知模型。
- **参数与环境变量**：**必须传入且仅能传入 1 个文件路径参数**。不支持环境变量。

#### 6. [scripts/generate_assembly_candidate.mjs](../scripts/generate_assembly_candidate.mjs)
- **用途**：验证源模型 SHA-256 哈希值，提取 `#549 Yaw轴装配体2.1改` 的父链世界平移，生成取反平移补偿后的候选模型、JSON 补丁及几何依据报告。
- **前置条件**：Node.js 18+，`web/models/hero_robot_clean.glb` 存在且哈希值吻合基线。
- **执行命令**：
  ```bash
  node scripts/generate_assembly_candidate.mjs
  ```
- **输入**：`web/models/hero_robot_clean.glb`。
- **输出**：`web/models/hero_robot_inferred.glb`、`web/models/repairs/yaw-offset-inferred.json`、`docs/model-editor/inferred-assembly/几何依据.json`。
- **覆盖风险**：**高风险**。直接覆盖候选模型、补丁文件以及文档目录中的几何依据数据。
- **参数与环境变量**：无参数，不支持环境变量。

### 5.4 几何审计与模型报告脚本

#### 7. [scripts/hero_assembly_audit.mjs](../scripts/hero_assembly_audit.mjs)
- **用途**：在世界坐标系下检查原样与候选模型的10对指定零件。AABB初筛通过后遍历全部三角形对，区分接触和面片交叉；未覆盖整车所有零件，也不能排除完全包含或证明制造公差合格。
- **前置条件**：Node.js 18+，原样与候选两份模型文件均存在。
- **执行命令**：
  ```bash
  node scripts/hero_assembly_audit.mjs
  # 或显式指定输出目录：
  OUTPUT_DIR=.tmp/ci/hero-assembly node scripts/hero_assembly_audit.mjs
  ```
- **输入**：`web/models/hero_robot_clean.glb` 与 `web/models/hero_robot_inferred.glb`。
- **输出**：`${OUTPUT_DIR}/audit.json`。
- **覆盖风险**：**极低**。默认输出到 `.tmp/ci/hero-assembly/` 临时目录，不修改任何模型或正式文档。
- **参数与环境变量**：**支持 `OUTPUT_DIR`**（默认 `.tmp/ci/hero-assembly`）。无命令行参数，不支持 `BASE_URL`、`BROWSER_PATH`。

#### 8. [scripts/model_report.py](../scripts/model_report.py)
- **用途**：提取并对比源 CAD 文件与项目输出轻量化 GLB 的文件体积、独立三角面数、节点数和 SHA-256 哈希。
- **前置条件**：Python 3 标准库。
- **执行命令**：
  ```bash
  python3 scripts/model_report.py
  ```
- **输入**：脚本内硬编码的本机Downloads源模型，以及 `web/models/hero_robot_clean.glb`、`web/models/diff_car_teaching.glb`。
- **输出**：`docs/model-stats.json`。
- **覆盖风险**：覆盖 `docs/model-stats.json`。源模型路径不可通过参数修改；换机运行前需检查脚本中的 `source`，缺少源文件会报错。
- **参数与环境变量**：无参数，不支持环境变量。

### 5.5 模型静态校验与测试脚本

#### 9. [scripts/validate_models.mjs](../scripts/validate_models.mjs)
- **用途**：调用官方 `gltf-validator` 引擎对项目内的 3 份核心 GLB 模型进行全量规范与 Buffer 结构静态检测，存在 Error 时非零退出。
- **前置条件**：Node.js 18+，已执行 `npm ci`（安装 `gltf-validator`）。
- **执行命令**：
  ```bash
  node scripts/validate_models.mjs
  # 保护文档不被覆盖的推荐命令：
  OUTPUT_DIR=.tmp/ci/models node scripts/validate_models.mjs
  ```

- **输入**：`web/models/hero_robot_clean.glb`、`hero_robot_inferred.glb`、`diff_car_teaching.glb`。
- **输出**：`${OUTPUT_DIR}/gltf-validation.json`。
- **覆盖风险**：**中风险**。默认输出至 `docs/gltf-validation.json`！若需保护归档文件，须显式设置 `OUTPUT_DIR=.tmp/...`。
- **参数与环境变量**：**支持 `OUTPUT_DIR`**（默认 `'docs'`）。无命令行参数，不支持 `BASE_URL`、`BROWSER_PATH`。

## 7. 常见故障排查与现场提示

1. **页面白屏或模型不显示**：
   - 检查控制台（Console）与网络（Network）标签页，确认本地服务器是否正在运行且资源返回 200。
   - 确认显卡驱动与浏览器 WebGL 2.0 支持正常（访问 `chrome://gpu` 查看）。
   - 确保通过 `http://127.0.0.1:...` 访问，**绝不能以 `file://` 直接双击打开**。
2. **整车模型局部部件在原点空间悬空**：
   - 战队英雄整车模型自带偏置子装配 `#549 Yaw轴装配体2.1改`，这是 CAD 导出的真实工程状态，并非前端 JavaScript 加载异常或网格丢失。独立查看页默认对其进行隐藏，课堂对照页默认采用主体居中取景。
3. **投影电脑运行卡顿**：
   - 适当降低投影机输出分辨率（例如降至 1366×768 或 1280×800）或将浏览器窗口缩放调至 100%。
   - 独立查看器中若开启“线框模式”可能会增加几何绘制调用开销，低配电脑建议保持默认实体材质观察。
4. **小车在仿真中驶出视野**：
   - 点击界面左上方的“跟随视角”运镜，或点击“归位”（或“重置小车位置”）一键恢复到起始坐标。
