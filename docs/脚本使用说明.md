# 脚本使用说明

## 只想上课：无需安装开发包

从项目根目录执行：

```bash
bash scripts/run_server.sh 8080
```

打开 http://127.0.0.1:8080/ ，整车单独查看为 `/viewer_full.html`。端口占用会递增，以终端输出为准。Ctrl+C关闭。默认只绑定127.0.0.1，不向同网设备或公网开放。需Python3、`ss`与现代WebGL浏览器。

所有JS、模型与图片已在本地，授课不需要npm安装或在线CDN。不要用文件管理器直接双击HTML。推荐至少1280×800投影分辨率；更小屏幕不是本版目标。

## 课堂按键

- →、空格、下一步：推进；←返回；R重新开始本步。
- 第7步：点“推进指令链”三次，观察高亮与传播标记。
- 第8步：前进／后退／左转／右转／停止。
- 第9步：拖两根独立滑块，中心停止；固定／跟随切换不重置运动。
- “暂停演示”冻结仿真，仍可查看画面；“重置小车位置”清空轨迹、轮速与姿态。
- 第10步：点功能区高亮，供电和控制位置未知则如实提示。
- 代码抽屉只读文本，不编译、不连接CAN、不驱动任何电机。

## 首次开发环境（需要联网）

不用于课堂当天临时准备：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
npm ci
npx playwright install chromium
```

本机若虚拟环境没有pip，可使用 `uv pip install --python .venv/bin/python -r requirements.txt`。不安装到全局Python。外网下载按本机代理配置，HTTP/HTTPS为`http://127.0.0.1:7897`；npm可用`npm_config_proxy`与`npm_config_https_proxy`，Playwright可用`HTTPS_PROXY`。代理不可达时停止下载，不静默绕过。

Playwright浏览器不受当前发行版支持时可设置`BROWSER_PATH=/绝对路径/chrome`。本次验收使用项目`.tmp/browser/chrome-linux/chrome`；它是可再生开发产物，不纳入Git。正式复现应提前安装Playwright浏览器或指定本机浏览器。

## 可选重建命令

以下会覆盖**本项目生成文件**，不改下载目录原文件：

```bash
.venv/bin/python scripts/generate_diff_car.py
.venv/bin/python scripts/optimize_models.py /绝对路径/整车5.glb
.venv/bin/python scripts/generate_diagrams.py
.venv/bin/python scripts/model_report.py
node scripts/validate_models.mjs
npm test
```

- `generate_diff_car.py`：生成具名节点的教学车GLB；可额外传入输出路径。
- `optimize_models.py`：调用固定在锁文件的本地gltfpack，`-si 0.08`有损简化，保留名称及材质，禁用额外量化依赖；随后清理孤立图片。工具缺失会报错，不自动联网。
- `resize_glb_textures.py`：处理输出GLB的图片。无纹理引用且无扩展时删除孤立图片并重映射bufferView；若有引用则仅缩小图像。该脚本应只用于受控项目输出，不当成任意GLB通用无损清理器。
- `model_report.py`：读取本机Downloads原模型与项目输出，生成大小、面数和SHA256报告。迁移机器须修改原模型位置。
- `generate_diagrams.py`：重建十张教学SVG；示意图不是实拍。

## 浏览器验收、PDF与视频

先运行静态服务器，在另一个终端执行：

```bash
node scripts/browser_check.mjs http://127.0.0.1:8080
node scripts/export_docs.mjs
node scripts/record_demo.mjs http://127.0.0.1:8080
```

- 验收脚本禁止外网请求，失败会非零退出。更新`docs/browser-results.json`和页面截图，软件渲染帧率不是目标GPU性能。脚本启动浏览器禁用沙箱，只访问本地受信任项目，不能复用于不受信网页。
- PDF脚本将三份Markdown转成A4中文PDF，依赖系统中文字体（本机Noto CJK）。图片内嵌，分页可文字提取。输出在`docs/pdf/`。
- 视频脚本依赖`ffmpeg`，固定仿真步长截取十步与转弯操作，生成无声H.264 MP4；**不是实车录像，也不是实时性能录像**。临时帧在`.tmp/demo-frames/`，可安全重建。
- 最终成品：三份PDF、PNG页面截图、`docs/media/教学仿真操作演示.mp4`。来源与使用许可见`素材与来源.md`。

## 排障

页面空白先检查Console/Network及WebGL可用性；整车未出现检查GLB路径与加载提示。源CAD自带偏置子装配不是JS加载失败，不凭空补装。降低浏览器缩放/投影分辨率可缓解负载，但须现场验证。暂停后想看运镜应点继续；小车驶远时重置或切跟随。

实物照片存在器件类型参考差异；未取得同款电池电芯照片、电子件位置认证前保持缺项说明，不用示意图冒充。
