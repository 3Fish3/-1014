# RoboMaster 电控教学系统使用报告

## 1. 当前能做什么

本项目面向 RoboMaster 电控组新学员，提供整套离线 Web 三维教学课件与结构查看工具：
1. **第一章：英雄机器人结构导览**：通过六个讲师手动控制的场景（开场 → 整车 → 云台 → 底盘 → 发射机构 → 电机过渡），建立机械与电控的整体框架，支持部件高亮、四轮组与驱动电机逐项隔离、一键恢复整车与重播，底部无缝衔接第二章。
2. **第二章：从零制造一台能移动的机器人**：通过十步课件讲解车架、轮组、电机、驱动器、供电、主控及双轮差速运动仿真（轮组自转、预设动作、差速滑块与轨迹积分），最后在 Step 10 与英雄机器人整车结构对照。
3. **独立结构查看器**：支持表面拾取真实源节点、结构树搜索定位、显隐/隔离及相机取景保持，默认完整展示对齐后的英雄机器人整车。
4. **装配修复工作台**：支持在模型原始坐标系中调整节点变换、撤销重做、哈希绑定 JSON 补丁导出与草稿 GLB 生成。

英雄模型用于静态结构观察，尚未实现整车行驶、云台关节运动、碰撞或动力学仿真。网页不连接实体电机或 CAN 总线；哨兵代码抽屉只供课后阅读。

## 2. 启动与页面入口

在项目根目录运行：

```bash
bash scripts/run_server.sh 8080
```

脚本需要 Bash、Python 3 和 `ss`，当前按 Linux 环境使用。它仅绑定 `127.0.0.1` 本机回环地址；端口占用时会递增，访问地址以终端输出为准。停止服务时按 `Ctrl+C`。前端依赖已随项目保存，日常打开不需要联网安装开发包。

| 入口 | 地址 | 用途 |
| --- | --- | --- |
| **第一章：结构导览** | <http://127.0.0.1:8080/hero-tour.html> | 六场景英雄整车结构导览，默认使用 STEP 对齐模型 |
| **第二章：课堂课件 (V2)** | <http://127.0.0.1:8080/ui-v2.html> | 十步白色投影主课件，含双轮差速仿真与 Step 10 实车对照 |
| **独立结构查看** | <http://127.0.0.1:8080/viewer_full.html> | 表面拾取、树形过滤、显隐、隔离和观察整车结构 |
| **装配修复工作台** | <http://127.0.0.1:8080/model-editor.html> | 调整节点变换，导出补丁或草稿 GLB |
| **第二章：旧版课件 (V1)** | <http://127.0.0.1:8080/index.html> | V1 回归参考，网站根路径 `/` 默认进入此页 |

请通过 HTTP 地址访问，**严禁双击 HTML 使用 `file://` 打开**。浏览器需要支持 WebGL 2.0 和 ES 模块。已有截图和交互验收覆盖 1920×1080、1366×768；其他分辨率和课堂硬件需现场检查。

## 3. 第一章：英雄机器人结构导览怎么用

打开 `hero-tour.html`，由讲师手动推进：
- **场景 0（开场）**：英雄机器人整车缓慢旋转，讲师可点击旋转按钮暂停旋转，鼠标拖拽可自由观察。
- **场景 1（整车）**：依次揭示云台、底盘、发射机构三大核心模块，点击卡片对应区域高亮显示。
- **场景 2（云台）**：点选水平旋转（Yaw）、俯仰（Pitch）与同步带传动位置，显示方向指示几何箭头（不驱动机械关节）。
- **场景 3（底盘）**：展示承载车架、四轮组（A/B/C/D）与底盘 M3508 驱动电机，支持隔离单项细节观察；点击驱动电机后停留，引出动力驱动思考。
- **场景 4（发射机构）**：展示发射通道所在结构、拨弹装配与三处摩擦轮动力部件，如实标注待确认项。
- **场景 5（电机与过渡）**：恢复整车并回顾全车电机分布，底部直达第二章电机与动力教学入口。
- **全局交互**：运镜平滑且支持鼠标拖拽立即打断；“恢复整车”退出隔离，“重播”重新播放当前场景动画。

## 4. 第二章：课堂课件怎么用

打开 `ui-v2.html`，按底部导航依次推进：任务、轮组、电机、驱动器、电池与稳压、主控、指令路径、预设动作、差速滑块、实车对照。右侧知识卡片随步骤更新，讲师工具提供步骤跳转与参考内容。

- **第 7 步**：推进指令链 3 次，依次观察主控（青色信号）、驱动器（橙色功率）与电机的传播标记；可以随时暂停演示。
- **第 8 步**：选择前进、后退、左转、右转或停止，直观观察两轮同向/异向转动与小车移动。
- **第 9 步**：分别拖动左右轮无数值滑块，观察轮速差与真实积分轨迹；可切换固定/跟随视角，或点击“归位”清空运动轨迹与位姿。
- **第 10 步**：教学车和英雄模型各有独立观察视区（单 WebGLRenderer 双视区裁剪隔离），可分别旋转、缩放、复位。功能按钮用于对照承载车架、动力轮组、驱动电机、电源管理与电调主控；英雄侧未确认的供电、主控位置保持“未确认”。

### 第 10 步模型选择说明

第 10 步**默认加载 STEP 对齐模型 (`hero_robot_step_aligned.glb`)**，云台与底盘装配位置完整吻合。用户可使用右上角下拉框或 URL 参数切换：
- 默认：`hero_robot_step_aligned.glb`（STEP 对齐，位置经用户确认）
- 原样参考：`ui-v2.html?step=10&assembly=original`（保留原始 CAD 偏置子装配作为历史基线对照）
- 旧推定候选：`ui-v2.html?step=10&assembly=inferred`（基于父链反向平移补偿的旧推定装配，标记未机械核验）

## 5. 独立结构查看怎么用

打开 `viewer_full.html`，用鼠标单击模型表面，或在左侧结构树搜索名称/节点编号后选择。选中结构显示橙色包围框；拖动用于转动视角，滚轮用于缩放。

| 操作 | 方法 |
| --- | --- |
| 隐藏选中 | 按钮或 `H`；装配组隐藏会影响其子件 |
| 显示选中 | 按钮或 `Shift+H`；打开必要祖先，保留其他子件的隐藏状态 |
| 隔离选中 | 暂时只显示所选结构及必要祖先 |
| 退出隔离 | 恢复进入隔离前的显隐状态快照 |
| 选择父组 | 沿结构树向上选择装配组 |
| 聚焦选中 | 按钮或 `F`，按选中结构的可见几何重新取景 |
| 适配可见结构 | 按当前全部可见几何重新取景 |
| 全部显示 | 显示所有结构，包括所有装配组 |
| 恢复默认 | 恢复当前所选版本的初始显隐状态 |
| 清除选择 | `Esc`；不改变零件显隐 |

**视角保持原则**：隐藏、显示、隔离、退出隔离、全部显示及恢复默认**不主动重置镜头**。需要重新取景时再点聚焦（`F`）或适配按钮。

### 模型版本与 #549 装配组

- **默认 STEP 对齐版**：默认加载 `hero_robot_step_aligned.glb`，`#549 Yaw轴装配体2.1改` 及其 11 个子件完整正常显示，无需手动操作。
- **原样参考版 (`?assembly=original`)**：加载原样模型，保留旧策略，默认隐藏原点悬空的 `#549` 偏置组，点击“全部显示”可恢复观察。
- **旧推定版 (`?assembly=inferred`)**：加载反向平移补偿模型，仅供历史算法对比。

## 6. 工作台与维护注意事项

工作台（`model-editor.html`）在模型原始坐标系中提供移动、旋转、撤销/重做和 JSON 补丁导入导出；平移按源文件坐标单位解释，不能直接当作毫米。导出草稿 GLB 只改变目标节点变换矩阵，二进制几何数据（BIN chunk）byte-for-byte 严格一致。补丁绑定源文件 SHA-256，导出不自动替换课堂资产。

日常授课只需启动静态服务器。资产重建、缩图、PDF 及视频导出仅供工程维护时运行。先查 [脚本使用说明](脚本使用说明.md)，不要把重建流程当作每次上课的启动步骤。
