# RoboMaster 电控教学系统使用报告

## 1. 当前能做什么

本项目用于第二章电控入门课：通过十步课件讲解车架、轮组、电机、驱动器、供电、主控及双轮差速运动，再与英雄机器人整车结构对照。

已实现的运动演示针对教学小车，包括轮组转动、预设动作、差速滑块、轨迹与指令传播。英雄模型用于静态结构观察，尚未实现整车行驶、云台关节运动、碰撞或动力学仿真。网页不连接实体电机或 CAN 总线；代码抽屉只供课后阅读。

## 2. 启动与页面入口

在项目根目录运行：

```bash
bash scripts/run_server.sh 8080
```

脚本需要 Bash、Python 3 和 `ss`，当前按 Linux 环境使用。它仅绑定 `127.0.0.1`；端口占用时会递增，访问地址以终端输出为准。停止服务时按 `Ctrl+C`。前端依赖已随项目保存，日常打开不需要联网安装开发包。

| 入口 | 地址 | 用途 |
| --- | --- | --- |
| 课堂课件 | <http://127.0.0.1:8080/ui-v2.html> | 十步白色投影界面 |
| 独立结构查看 | <http://127.0.0.1:8080/viewer_full.html> | 选择、显隐、隔离和观察整车 |
| 装配修复工作台 | <http://127.0.0.1:8080/model-editor.html> | 调整节点变换，导出补丁或草稿 |
| 旧版课件 | <http://127.0.0.1:8080/index.html> | V1 回归参考，网站根路径也进入此页 |

请通过 HTTP 地址访问，不要双击 HTML 使用 `file://` 打开。浏览器需要支持 WebGL 和 ES 模块。已有截图和交互验收覆盖 1920×1080、1366×768；其他分辨率和课堂硬件需现场检查。

## 3. 课堂课件怎么用

按底部导航依次推进：任务、轮组、电机、驱动器、电池与稳压、主控、指令路径、预设动作、差速滑块、实车对照。右侧知识卡片随步骤更新，讲师工具提供步骤跳转与参考内容。

- 第7步：推进指令链，观察控制与供电关系；可以暂停演示。
- 第8步：选择前进、后退、转向或停止，观察教学小车的运动。
- 第9步：分别拖动左右轮滑块，观察轮速差与轨迹；可切换固定/跟随视角，或归位重置。
- 第10步：教学车和英雄模型各有独立观察区，可分别旋转、缩放、复位。功能按钮用于对照车架、轮组、电机、供电与控制；英雄侧未确认的供电、主控位置保持“未确认”。

第10步默认使用原样模型。可用下拉框或 <http://127.0.0.1:8080/ui-v2.html?step=10&assembly=inferred> 查看推定候选。候选的几何证据支持平移补偿，但没有原 CAD 或实物核验，不能据此认定机械装配正确。

## 4. 独立结构查看怎么用

打开 `viewer_full.html`，用鼠标单击模型表面，或在左侧结构树搜索名称/节点编号后选择。选中结构显示橙色包围框；拖动用于转动视角，滚轮用于缩放。

| 操作 | 方法 |
| --- | --- |
| 隐藏选中 | 按钮或 `H`；装配组隐藏会影响其子件 |
| 显示选中 | 按钮或 `Shift+H`；打开必要祖先，保留其他子件的隐藏状态 |
| 隔离选中 | 暂时只显示所选结构及必要祖先 |
| 退出隔离 | 恢复进入隔离前的显隐状态 |
| 选择父组 | 沿结构树向上选择装配组 |
| 聚焦选中 | 按钮或 `F`，按选中结构的可见几何取景 |
| 适配可见结构 | 按当前全部可见几何重新取景 |
| 全部显示 | 包括默认隐藏的 `#549` 装配组 |
| 恢复默认 | 恢复初始显隐状态，再次隐藏 `#549` |
| 清除选择 | `Esc`；不改变零件显隐 |

隐藏、显示、隔离、退出隔离、全部显示及恢复默认**不主动重置镜头**。需要重新取景时再点聚焦或适配按钮。若已开启自动旋转，或拖动阻尼尚未结束，相机仍会按这些已有动作运动。

快捷键在搜索框、按钮等交互元素获得焦点时不生效。显隐状态只保存在当前页面内存，刷新恢复默认；没有保存视图到文件的功能。

### 默认隐藏的悬空组

原样模型的 `#549 Yaw轴装配体2.1改` 位于 `389 → 543 → 549` 层级，是整组装配，不是单独一个电机。独立查看页按用户选择默认隐藏它，源 GLB 没有删除零件。点击“全部显示”可恢复观察。

这与课堂第10步不同：课堂原样模型的“主体取景”只在计算相机范围时排除偏置组，没有隐藏该组。重复平移是目前的几何推断，不作为已经机械认证的导出错误结论。

## 5. 工作台与维护注意事项

工作台在模型原始坐标系中提供移动、旋转、撤销/重做和 JSON 补丁导入导出；平移按源文件坐标单位解释，不能直接当作毫米。导出草稿 GLB 只改变目标节点变换，保留二进制几何数据。补丁绑定源文件 SHA-256，导出不自动替换课堂资产。

日常使用只需启动服务器。资产重建、缩图、PDF及视频导出供维护时运行，其中部分脚本会覆盖既有模型或交付文件。先查 [脚本使用说明](脚本使用说明.md)，不要把重建流程当作每次上课的启动步骤。
