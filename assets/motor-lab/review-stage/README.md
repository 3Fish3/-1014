# 电机实验台阶段建模资料

本目录按用户本次授权保存到公开审核分支，供代码/模型审核使用。第三方素材的商业或其他再分发条款仍须逐项核实；本目录不是统一开源许可声明。

## 入口

- [完整目录及SHA-256](catalog.json)：18组主器件、扩展和附件候选，包含18份原始STEP和28份GLB。
- C板已着色GLB位于[上级C板资产](../c-board/c-board-official-white-silver.glb)，不重复存放；连同该件总计29份GLB。
- [审核说明](../../../docs/motor-lab/REVIEW.md)：启动方法、代码入口、现有行为与待审问题。
- `models/<id>/source.step`：原件的逐字节副本，不是修复后重新导出的CAD。
- `models/<id>/web.glb`：本阶段当前展示候选，`high.glb`为另一个三角化参数档位，不保证每件三角数更多或已做误差认证。
- `models/<id>/history/`：代理与主模型的阶段报告。部分报告是早期快照，当前状态以catalog及审核说明为准。
- `recipes/`：本阶段转换/配色脚本快照，含旧任务路径和哈希约束；复现时需要按新目录调整输入。不是开箱即用的流水线。
- `evidence/`：历史截图、模型检查和浏览器记录；本次归档没有重新运行测试。

## 状态不能混淆

当前接线实验台使用C板、中心板2、C620、M3508、TB47D和兼容电池架。其他器件是扩展/参考资产。

- `dm4310`：原件在当前FreeCAD导入路径存在两个无效BRep对象，未生成GLB。
- `rocker-switch`：外形审查不通过，保留拒收样本，禁止冒充真实船型开关。
- `xt60-f`、`xt60-m`：板端候选，不是完整成品线或已核线端配对。
- `irm-module`：板载封装候选，不替代已选TB47D电池。
- `old-center`：旧代中心板，不套用中心板2电气定义。
- `usb-uart`：适配器候选，逻辑电平及与C板的最终接线未选定。随附上游TAPR OHL文本，具体适用范围按上游声明处理。
- `battery-rack/history/manifest.invalid-json.txt`：原代理留下的损坏JSON，按原字节保存为文本，不是有效配置。

颜色为展示近似；米制GLB在运行时共同放大20倍，不单件归一化。文件大小不是内存。

电池架颈部摆放通过名义BRep体积相交检查，不代表卡扣、装配公差或电气接触认证。线头和端点仍为功能示意，精确针序、料号、配合面及电池架输出身份有待核。

## 本次未包含

不含凭据、其他项目、浏览器或依赖缓存、无关教学修改、重复备份、日志和运行PID。未修改源模型，未操作实物。

历史制作脚本以`.py.txt`／`.mjs.txt`保留原字节，供审核阅读，不作为本分支可直接执行模块。文件原名与SHA见catalog；正式运行入口仍为scripts与web下的代码。
